### Otel Arama Formu (Booking.com / Expedia standardı):
- **Nereye** → şehir/otel adı autocomplete
- **Giriş / Çıkış** → date range picker (default 1 gece)
- **Oda + Misafir paneli** (tek dropdown):
  - Oda 1: Yetişkin (1-4) + Çocuk (0-4, her çocuk için yaş 0-17)
  - "+ Oda Ekle" butonu (max 6 oda)
  - Her oda bağımsız: çıkarılabilir
- **Promosyon Kodu** → opsiyonel input
- **Ara butonu** → tam genişlik, brand rengi

### Tur Arama Formu (GetYourGuide / Viator standardı):
- **Nereye** → destinasyon autocomplete
- **Başlangıç + Bitiş (opsiyonel)** → date picker
- **Kategori** → dropdown (6 kategori)
- **Misafir paneli**:
  - Yetişkin (1-20) + Çocuk 3-12 (0-10) + Bebek 0-2 (0-5)
  - "Bebekler kucakta seyahat eder" helper text
- **Ara butonu** → geniş, brand rengi

### Implementasyon
- `SmartSearchContainer.tsx` yeniden yazıldı:
  - `GuestConfig` / `RoomConfig` tipleri (oda bazlı)
  - `RoomGuestPanel` — Booking.com tarzı multi-room guest selector
  - `TourGuestPanel` — yetişkin+çocuk+bebek (10 satırlık basit panel)
  - `DateInput` — native date picker, placeholder, brand focus ring
  - `LocationInput` — autocomplete dropdown, 10 Turkish city
  - Promo code input (otel tab)
  - Canlı MOCK sonuçlar (filter + card preview)
  - Tümü dark mode uyumlu
