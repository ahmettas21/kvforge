## 2026-05-23 — PMSC RAG Memory System

### PMSC → OpenClaw Kalıcı RAG Bellek
- **Konsept**: PMSC'yi OpenClaw'un kalıcı vektör belleği yapmak. Her konuşma otomatik encode edilsin, yeni sorularda geçmiş context otomatik çekilsin.
- **`memory_hook.py`** yazıldı ve test edildi: `/home/turk/projects/openclaw-pmsc-skill/memory_hook.py`
  - `get_relevant_context(user_msg)` → PMSC store'da semantik arama yapar, score > 0.35 sonuçları döndürür
  - `auto_encode_turn(user_msg, ai_response)` → konuşma turunu encode edip store'a kaydeder
  - `command_save_fact(text)` → "hafızana al: bilgi" komutu için facts koleksiyonuna kaydeder
  - `command_what_i_know()` → tüm koleksiyonları listeler
  - `command_list_memory(collection)` → belirli bir koleksiyonu listeler
  - **Doğrudan cosine hesaplama** kullanır (sentence-transformers embedder ile batch embed, her item için decode yapmaz)

### Test Sonuçları (BAŞARILI ✅)
- `python3 memory_hook.py save "ilker pytorch yerine numpy tercih ediyor"` → facts'e kaydedildi
- `python3 memory_hook.py search "pytorch mu numpy mu kullansam?"` → **0.73** score ile facts kaydını buldu
- `python3 memory_hook.py search "embedding kalitesi nasıl"` → **0.62** score ile eski memory kaydını buldu
- `python3 memory_hook.py list facts` → facts koleksiyonunu listeledi
- `python3 memory_hook.py list memory` → memory koleksiyonunu listeledi
- `python3 memory_hook.py know` → tüm koleksiyonları gösterdi
